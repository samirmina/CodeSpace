About the Desktop GUI

Circular Timer

Watch-style Pomodoro timer with custom duration, pause/reset, and completion notifications.

Task Management

Full task CRUD with priority, status, tags, due dates, and user assignment.

Session History

Track Pomodoro sessions and productivity reports with detailed analytics.

JSON Persistence

Per-user data stored in JSON files with optional PostgreSQL synchronization.

Launch Instructions

  • Option 1 — Docker: Run docker compose up to start the web app and PostgreSQL. The JavaFX GUI launches from this page via the button above.
  • Option 2 — Native JAR: Build with mvn package and run java -jar target/chronos-1.0.0-SNAPSHOT.jar for the web app, then launch JavaFX from the button.
  • Option 3 — Standalone JavaFX: Compile and run src/Main.java directly with JavaFX 21 SDK on the module path.
